## 2. Simple Princess companion plan — COMPLETED / 3 POSTERS APPROVED

### Why
The existing Fairy-Tale Princess set is attractive and useful for style inspiration, but it is too detailed to serve as the easiest drawing-along entry point.

### Keep
Do not replace:
- Design a Fairy-Tale Princess
- Princess Hair, Dress & Royal Details
- Graceful Princess Poses

### Add — 3 beginner companions

1. **Draw a Simple Princess Face**
   - simple head construction
   - clear eye placement
   - one readable hair mass
   - minimal crown/tiara
   - clean line before decoration

2. **Build a Simple Princess Dress**
   - torso / bodice block
   - large skirt shape
   - simple sleeves
   - 3–5 clear folds only
   - one small decorative motif

3. **Draw a Simple Princess Pose**
   - gesture
   - supporting leg / balance
   - simple arm placement
   - skirt follows the pose
   - finish one full-body readable silhouette

### Visual rule
- visibly simpler than the existing Princess set
- full construction lines must be readable
- light pastel color only after line clarity
- fewer ornaments
- one learner-copyable character per lesson
- same visual family as current Character / SG-01 posters

Role on website:
- beginner companion / easier entry
- existing Princess set remains the richer design/style set

## 3. Clear Manhua companion plan — NEXT

### Why
The current Manhua set communicates elegance, hair/fabric flow and decorative detail well, but the learner does not get enough clean full-body structural construction.

### Keep
Do not replace:
- Draw a Manhua-Inspired Character
- Elegant Manhua Details
- How to Draw Manhua Movement

### Add — structure-first companion set

**Required 1 — Draw a Full-Body Manhua Figure**
- gesture line
- head / chest / hips
- simple limbs
- full-body proportion
- clean silhouette
- finish with restrained hair/clothing

**Required 2 — Build Manhua Clothing from Simple Shapes**
- body construction remains visible
- sleeve / skirt / robe masses
- gravity and attachment points
- simple fold directions
- refined clothing without losing the body underneath

**Optional 3 — Manhua Pose to Finished Figure**
- gesture
- body blocks
- clothing masses
- hair flow
- clean final
- same character / camera / pose throughout

### Visual rule
- full body must be visible
- construction comes before decoration
- large shapes before strands/folds
- readable linework
- soft, limited color
- no decorative effects that hide anatomy
- cumulative steps preserve the same pose and camera

Initial recommendation:
- produce the first **two** companions first
- create the third only if the first two still leave a real bridge gap
