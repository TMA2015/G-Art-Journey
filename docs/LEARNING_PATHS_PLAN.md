# Start Here / Learning Paths — Product + Academic Plan

**Status:** PROPOSAL FOR OWNER REVIEW  
**Date:** 2026-10-02  
**Implementation:** not started  
**Goal:** help a new learner answer **“What should I learn next?”** without turning G-Art Journey into a rigid curriculum.

## 1. Why add Learning Paths now

G-Art Journey has grown from a small guide collection into a broad learning library:
- Pencil foundations and portrait work
- Human Drawing
- Core Drawing Skills
- 6 Character Art topics × 3 lessons
- Landscape / perspective
- Watercolor
- 2 Digital Art series × 5 lessons
- 23 Reference Library sheets

The catalog is now rich enough that a beginner can enjoy browsing but still feel unsure where to begin.

Learning Paths should add **guidance**, not restrictions.

## 2. Product principles

1. **Suggested order, never locked order.**  
   Learners may open any lesson at any time.

2. **Short visible routes.**  
   A path should usually show about 4–8 main checkpoints. Larger series can appear as one checkpoint with their internal lessons nested underneath.

3. **Core vs optional is explicit.**  
   Use labels such as **Core**, **Optional**, **Choose one** and **Explore more** instead of pretending every learner needs every guide.

4. **Use existing lessons first.**  
   Version 1 should not require new teaching posters. The purpose is to organize what already exists.

5. **Reference Library is support, not homework.**  
   Reference sheets should appear beside relevant steps as optional visual vocabulary.

6. **No progress/account system in v1.**  
   Start with clear navigation. Progress tracking can be considered later if it materially helps.

7. **Counts and titles come from data.**  
   Do not duplicate hard-coded lesson counts in page copy.

## 4. Path A — Drawing Basics

**Purpose:** build control, form, value and texture before specializing.

**Best for:** a learner who says “I want to draw, but I do not know where to start.”

### Core route

| Step | Lesson | Slug | Why here |
| --- | --- | --- | --- |
| 1 | Pencil Control — Lines, Pressure & Marks | `pencil-control-lines-pressure` | Learn basic mark control before detail. |
| 2 | Shade Simple Forms | `pencil-simple-forms` | Connect light, value and three-dimensional form. |
| 3 | Draw Everyday Objects | `pencil-everyday-objects` | Apply simple forms to recognizable objects. |
| 4 | Texture with Graphite | `pencil-textures` | Add surface variety without losing big shapes. |

### Finish / branch

After Step 4, show:
- **Draw People**
- **Create Characters**
- **Draw Places**
- **Watercolor Basics**
- **Digital Art Basics**

This path deliberately ends with a choice instead of forcing a fifth unrelated lesson.

## 6. Path C — Create Characters

**Purpose:** turn basic face/figure knowledge into intentional character design.

**Recommended first:** `face-basics` or equivalent confidence drawing a simple head.

This path is intentionally **branching**, because learners should not be required to study every Character Art family.

### Core route

1. **Character Design Lab**  
   `four-character-face-approaches`  
   Learn how controlled choices in face shape, features, hair silhouette and line treatment change identity.

2. **Choose one Character Art topic**
   - Manga
   - Manhwa / Webtoon
   - Manhua
   - Cartoon / Comics
   - Chibi Characters
   - Fairy-Tale Princess

3. **Topic Lesson 1 — Build the character**  
   Open the first lesson of the chosen topic.

4. **Topic Lesson 2 — Explore variation/details**  
   Open the second lesson of the same topic.

5. **Topic Lesson 3 — Apply pose/story/action**  
   Open the third lesson of the same topic.

6. **Add one supporting skill — choose what your character needs**
   - Hands — `hands-simple-forms`
   - Hair — `hair-masses`
   - Fabric — `fabric-tension-gravity`
   - Figure balance — `standing-figure`

7. **Make your own variation**
   Use the Reference Library for pose, motion, hair or clothing ideas without copying one finished design.

### Important product behavior

The path should dynamically preserve the learner's selected Character Art topic through Steps 3–5. It should never imply that Manga → Webtoon → Manhua → Cartoon → Chibi → Princess is a required sequence.

## 10. Reference Library role

Reference Library should be shown as a persistent helper:

> Browse poses, movement, hair and clothing. Pick one detail, combine ideas, then make it your own.

Recommended contextual links:
- Draw People → Poses / Motion / Hair / Clothing
- Create Characters → all four collections
- Chibi → Chibi filter
- Fairy-Tale Princess → Fairy-Tale Princess filter
- Draw Places / Watercolor / Digital → no forced reference link unless relevant

## 11. UI proposal — v1

Keep v1 intentionally simple.

### On Drawing Guides
Add one clear card/button near the top:

**New here? Start with a learning path →**

### On /start-here/
- six path cards
- short outcome sentence
- approximate scope
- expandable or anchored path detail below
- Core / Optional / Choose one labels
- existing lesson thumbnails reused
- no new illustration batch required
- no locked prerequisites
- no progress bar in v1

### On individual lessons
Optional lightweight footer:

**Where can I go next?**
- next suggested lesson in the active path
- return to path
- browse freely

Do not alter the existing previous/next behavior inside Digital Art series.

## 12. Academic / UX guardrails

- Paths are recommendations, not grade levels.
- Do not describe one path as “better” or “more advanced” unless a real prerequisite exists.
- Avoid age assumptions.
- Character Art topics are alternatives/branches, not a hierarchy of quality.
- Reference sheets never become mandatory completion items.
- If a path points to a topic with internal lessons, preserve that topic structure.
- A new lesson does not automatically enter a path; its role must be reviewed first.

## 13. Coverage check

The proposed six paths give every major current learning area a clear home.

Content intentionally treated as **optional / enrichment** rather than forced core:
- Eye Structure
- Facial Features in Pencil
- Pencil Portrait
- Faces at Different Ages
- Body Shapes / Silhouettes
- Fabric
- Character Face Design Lab extensions
- Reference Library sheets

This prevents the Start Here page from becoming another giant catalog.

## 14. Proposed implementation order after owner approval

1. Lock this path structure.
2. Add structured learning-path metadata in one data file.
3. Add automated path integrity tests:
   - referenced slugs/topics exist
   - no retired guide is used
   - dynamic topic branches resolve
   - counts derive from data
4. Build `/start-here/`.
5. Add one **Start here** entry point from Drawing Guides.
6. Run content consistency, guide distinctness, build and route verification.
7. Owner desktop/iPad QA.
8. Only then consider progress tracking or more paths.

## 15. Deferred until after v1

Do not include yet:
- accounts/progress tracking
- badges/streaks
- locked prerequisites
- estimated completion percentages
- AI-generated path personalization
- a large new batch of artwork

Those features should be justified by actual use, not added pre-emptively.
