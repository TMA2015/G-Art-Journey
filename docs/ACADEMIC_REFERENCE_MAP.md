# Phase 2 academic reference map

This document is a **content-quality reference**, not a bibliography that must be shown to every visitor. G-Art Journey should translate reliable drawing principles into short, friendly beginner guides without copying source wording or turning the site into an academic course.

## 1. Observational drawing fundamentals

### UC San Diego Extended Studies — Drawing I: Focus on Perception
https://extendedstudies.ucsd.edu/courses/drawing-i-focus-on-perception-art-x401-66

Useful principles:
- contour and line
- positive/negative space
- perspective
- shading
- highlight, cast shadow and reflected light
- proportion and sighting from observation

**G-Art use:** foundation for graphite, portrait, object and landscape lessons. We should teach seeing relationships before detail.

### Foothill College — Fundamentals in Drawing (ART 4A)
https://catalog.foothill.edu/course-outlines/ART-4A/

Useful principles:
- form
- value and light/shadow patterns
- perspective
- proportion
- composition
- observational chiaroscuro drawing

**G-Art use:** graphite lessons should progress from simple form/value decisions toward portraits and scenes.

## 2. Figure, head and hand structure

### Foothill College — Heads & Hands Drawing (ART 4E)
https://catalog.foothill.edu/course-outlines/ART-4E/

Useful principles:
- accurate proportions from observation
- head/hand anatomy and planes
- placement and size of facial features and fingers
- light and shadow on head/hands
- multiple viewpoints
- expressive heads/hands grounded in structure

**G-Art use:** eyes and hands should be taught as 3D structures, not decorative symbols.

### Stanford Continuing Studies — Art and Anatomy: Drawing the Human Hand
https://continuingstudies.stanford.edu/courses/detail/20261_ART-69

Useful principles:
- internal and external hand structure
- anatomical observation
- drawing from bones, models and reference
- structure first, individual style second

**G-Art use:** mandatory five-digit/anatomy check and a simple palm/thumb/finger construction before stylization.

### Academy of Art University — Figure Drawing
https://www.academyart.edu/courses/figure-drawing/

Useful principles:
- gesture
- proportion
- rhythm
- balance
- structure
- musculature

**G-Art use:** pose lessons should communicate balance and movement, not only outline.

## 3. Portrait and facial features

### Johns Hopkins Imagine — Figure Drawing: The Portrait
https://imagine.jhu.edu/classes/figure-drawing-the-portrait/

Useful principles:
- skull landmarks and proportions
- front, 3/4 and profile views
- feature structure
- muscles involved in expression
- simple geometry before tonal rendering
- neck/shoulder attachment

**G-Art use:** eye/nose/mouth lessons should relate features to head volume and viewpoint; expression should alter several features together.

## 4. Value, graphite and light

### Palomar College Pressbooks — Foundations of Drawing: Value
https://pressbooks.palomar.edu/art102/chapter/value/

Useful principles:
- value means lightness/darkness
- value patterns describe light and spatial form
- value scales provide a practical reference
- step scales and gradients have different uses

### CUNY OpenLab — Value Scales & Rendered Form
https://openlab.citytech.cuny.edu/woolley-comd2313fa17/2017/09/25/exercise-1-value-scales-rendered-form-in-value/

Useful principles:
- make a graphite value scale
- apply it to a simple sphere/form
- use observed light to create volume

**G-Art use:** first graphite tonal poster should use a small value scale plus one clearly lit simple form before portrait shading.

## 5. Perspective and depth

### Princeton University Art Museum — Drawing: Perspective 101
https://artmuseum.princeton.edu/art/stories-perspectives/video/art-making-l-drawing-perspective-101

Useful principles:
- one- and two-point perspective
- practical drawing perspective rather than architectural drafting only

### Palomar College Pressbooks — Foundations of Drawing: Perspective
https://pressbooks.palomar.edu/art102/chapter/perspective/

Useful principles:
- horizon line
- vanishing points
- orthogonals
- overlap and relative size
- translating 3D space to a 2D picture plane

**G-Art use:** pencil landscape lessons can combine simple linear perspective with overlap, scale and value/edge reduction for depth.

## 6. Digital drawing

### Adobe Learn — Get to know layers
https://www.adobe.com/learn/photoshop/in-app/introduction-to-layers

Useful principles:
- layers stack content
- visibility, order and selection are core concepts

### Gnomon — Digital Painting
https://www.gnomon.edu/academics/individual-courses/course-list/digital-painting/

Useful principles:
- digital work still depends on perspective, value, color, light and composition
- software is a tool, not a substitute for drawing fundamentals

### UCLA Extension — Color Methodologies
https://www.uclaextension.edu/design-arts/uxgraphic-design/course/color-methodologies-desma-x-48210

Useful principles:
- hue/value/intensity
- unity, variety, contrast, dominance, balance and harmony
- traditional and digital color interaction

**G-Art use:** keep app lessons tool-agnostic: layers first, then value/light, then color harmony.

## Translation rules for G-Art Journey

- Use short, common English in the public lesson.
- Never reproduce textbook passages or diagrams.
- Convert the principle into an original G-Art drawing exercise.
- Prefer one transferable skill over many facts on one poster.
- Use observational/reference checks for anatomy and proportion.
- Label stylized ratios as creative choices, not universal anatomy rules.
