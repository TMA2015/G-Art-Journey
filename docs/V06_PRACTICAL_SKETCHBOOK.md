# Practical Sketchbook — v0.6 candidate

## Why this small set

The family site is a place to wander and try things, not a graded course. New content connects the owner's interests (pencil portraits, human figures, pencil scenery) with a daughter's character drawing and optional digital coloring. Each activity works independently; there is no locked learning path.

## Five new English-first guides

| Guide | Topic | Practical outcome |
|---|---|---|
| Draw a Standing Figure with Simple Shapes | Figure drawing | Movement line → head/chest/hips → limbs → standing balance → outline |
| Shade a Portrait with a Pencil | Graphite | Light direction, large shadow masses, gradual shading and select highlights |
| Draw a Street That Feels Deep | Landscape | Eye level, one meeting point, size and contrast cues, focal point |
| Try Four Ways to Draw a Character Face | Character art | Four illustrative approaches with a shared construction, not national rules |
| Color a Face with Simple Layers | Digital | Base skin color, one shadow layer, warmth, highlights and comparison |

Two original educational SVG diagrams accompany the batch:
- `figure-simple-shapes.svg` (three-stage construction)
- `landscape-depth.svg` (eye level, near/far, focus)

These are explicitly diagrams, not finished reference artworks. Other new guides re-use topic images until original visual sequences are produced.

## Editorial principles

- Use everyday English first; define technical terms in place, e.g. `eye level (horizon)` and `one-point perspective` only after the drawing action.
- Observe real variation; avoid rigid figure proportions or a single body type.
- Manga, manhwa, manhua and US comics/cartoon are broad publishing contexts, not fixed drawing rules or ethnic facial stereotypes. The suggested visual approaches are creative options, not cultural classifications.
- Demonstrate why layers help, without insisting on many layers or costly software.
- No account, grading, scores, AI feedback, commerce or public comments.

## Planned art-asset production (separate review)

For each approved guide, build **one unified original reference image + 4–6 matching stage images** using the same pose/face/scene and camera angle. Each stage must visibly change a meaningful feature, not merely overlay numbered text on the final image. Prefer graphite texture for pencil lessons, lighter linework for character construction, and a clearly separated base/shadow/blush/highlight palette for digital color. Check consistent anatomy, perspective, hand count, leg visibility, tool-specific techniques, credit and originality before merging. We should not call current generic placeholders full tutorials.

## QA gates

- New slugs, category filters, links to related notes and responsive guide cards.
- Original SVGs render and download, no mixed-language public captions.
- Content tests and production build pass.
- Device QA (laptop and iPad) and editorial/art review before release.

## Storage guideline

The website uses GitHub as its only content and image platform. Family gallery images are web versions (clear, not oversized). Image budgets are soft warnings in CI; there is no new storage service or external backend. See [ASSET_POLICY.md](ASSET_POLICY.md).
