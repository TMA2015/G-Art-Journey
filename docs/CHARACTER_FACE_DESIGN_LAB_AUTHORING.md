## 2. Learning role

Primary skill:
- **controlled character-face design variation**

The learner starts from the **same basic head construction** and deliberately changes a small number of design decisions to create four distinct characters.

This lesson teaches:
- how face shape changes character feel
- how eyes, brows, nose and mouth work as a design system
- how hair silhouette changes identity
- how line weight changes graphic feel
- how to compare designs while keeping pose, camera angle and expression controlled

This lesson does **not** reteach:
- basic head construction
- detailed eye anatomy
- portrait graphite rendering
- Manga-specific face design
- Webtoon-specific face design
- Manhua-specific details
- Cartoon-specific shape libraries

## 3. Anti-overlap map

- **Draw a Face in Five Steps** → construction
- **Draw an Eye from Structure** → eye anatomy / lid structure
- **Manga / Webtoon / Manhua / Cartoon lessons** → style-family exploration
- **Try Four Ways to Draw a Character Face** → controlled design comparison from one shared base

## 4. Locked teaching sequence

1. **Start with one shared base head**
   - same head angle
   - same camera
   - same basic proportions
   - one simple neutral/slightly surprised expression

2. **Change the face shape**
   - soft round / oval / angular / graphic
   - retain the same underlying head direction

3. **Change the feature language**
   - eyes, brows, nose and mouth change as a coordinated set
   - avoid random independent feature swapping

4. **Change hair silhouette and line weight**
   - four distinct outer hair shapes
   - compare soft line, clean line, bold line and simplified graphic line

5. **Compare all four**
   - same broad expression
   - four clearly different character identities
   - encourage the learner to mix choices into an original design

## 5. Four approved design directions

### 01 — Soft & Gentle
- rounder / softer face
- calm eyes
- lighter line weight
- simple soft hair mass

### 02 — Bright & Expressive
- open eyes
- clearer brows
- more expressive mouth
- lively hair silhouette

### 03 — Cool & Angular
- sharper jaw / cheek design
- narrower eyes
- stronger line hierarchy
- cleaner angular hair shapes

### 04 — Playful & Graphic
- simplified / exaggerated face shape
- bold readable features
- stronger silhouette
- simple graphic line treatment

These are **design approaches**, not national or cultural labels.

## 7. Visual identity

- warm paper / editorial sketchbook feel
- graphite / clean pencil-line character studies
- restrained G-Art pastel accents
- English-first labels
- generous whitespace
- one coherent original female teen character base is acceptable, but the four variations must become visibly different character identities
- no copied existing anime / webtoon / comic characters

## 8. Human-image QA

Mandatory:
- coherent face anatomy for intended stylization
- both eyes aligned to head angle
- nose / mouth / jaw consistent with perspective
- ears placed plausibly when visible
- no accidental extra facial features
- hair must not merge incorrectly with eyes / face
- base head angle and camera remain consistent across all four variations
- differences must come from design choices, not accidental pose changes

Reject if:
- one face is just a recolor of another
- four faces are nearly identical
- expression changes are doing most of the design work
- features drift off-axis
- the infographic becomes a tiny 15–20 face comparison grid
- labels are unreadable
- unrelated Manga / Webtoon / Manhua / Cartoon category panels appear

## 9. Try it

**Draw one base head, then make four versions by changing face shape, feature design, hair silhouette and line weight. Keep the pose and expression nearly the same so you can compare your choices.**
