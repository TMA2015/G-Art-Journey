# Clear Manhua Companion — Implementation Plan

**Locked:** 2026-10-03  
**Purpose:** add beginner-friendly Manhua foundations that are genuinely drawable, while keeping the existing elegant Manhua set as style/inspiration material.

## Current Manhua set — KEEP

Do not replace:
- **Draw a Manhua-Inspired Character**
- **Elegant Manhua Details**
- **How to Draw Manhua Movement**

These remain useful for:
- style vocabulary
- flowing hair/fabric
- decorative detail
- movement inspiration

Their weakness is not that they are bad; it is that they do not provide enough clean, full-body, structure-first construction for a beginner.

## New companion set

### Poster 1 — Draw a Full-Body Manhua Figure
**Status:** NEXT

Teaching sequence:
1. Gesture / line of action
2. Head, ribcage and pelvis
3. Simple limbs and joints
4. Refine full-body proportion and silhouette
5. Add restrained hair/clothing while preserving the body underneath

Required outcome:
- one complete full-body figure
- readable anatomy
- clear construction
- elegant but simple Manhua feel

### Poster 2 — Build Manhua Clothing from Simple Shapes
**Status:** PLANNED AFTER POSTER 1

Teaching sequence:
1. Start from a visible body construction
2. Add simple torso/waist clothing masses
3. Add sleeve and skirt/robe masses
4. Show gravity and 3–5 major fold directions
5. Clean the clothing while keeping body structure readable

Required outcome:
- clothing should look flowing without hiding the underlying body
- learner can see where sleeves, skirt panels and folds come from

### Poster 3 — Manhua Pose to Finished Figure
**Status:** OPTIONAL / DECIDE AFTER POSTERS 1–2

Create only if Posters 1–2 still leave a real learning gap.

Possible sequence:
1. Gesture
2. Body blocks
3. Clothing masses
4. Hair flow
5. Clean final figure

Same character, same camera and same pose throughout.

## Locked visual standard

The new Manhua companion follows the **clarity-first direction established by the approved Simple Princess companion**.

### Core drawing treatment
- instructional figures are **line art first**
- no full color fill in the main construction sequence
- use clean, dark, readable lines
- hair strands must remain individually understandable without becoming dense texture
- body construction must remain visible until the lesson no longer needs it
- no glow, heavy texture, watercolor effects or decorative rendering over the teaching lines

### Layout
- portrait poster
- title/header: about **10–12% of poster height**
- Try it + Remember combined: about **7–10% of poster height**
- most vertical space belongs to the instructional drawings
- prefer **4 smaller construction steps + 1 large final full-body drawing** when it fits the lesson
- final drawing should be substantially larger than the construction thumbnails
- optional detail strip only when it teaches something concrete (fold direction, sleeve shape, hand placement, etc.)

### Color
- warm cream paper
- pastel colors only for:
  - step numbers
  - section labels
  - arrows
  - small decorative accents
- do not color the figure itself in the core tutorial panels unless owner explicitly requests it

### Character design
- elegant, readable Manhua-inspired proportions
- full body visible when the lesson requires full-body structure
- clothing simpler than the existing Manhua set
- fewer ornaments
- fewer hair accessories
- large hair masses before small strands
- no dense embroidery or decorative line noise

### Continuity
Within one poster:
- same character
- same pose
- same camera
- same proportions
- each step must visibly derive from the previous step

No step may jump from a simple construction to a different polished character.

### Anatomy QA
- plausible body proportions
- clear supporting leg / balance where relevant
- hands remain simple but anatomically credible
- exactly five fingers on every fully visible hand
- feet and limb joints must be coherent
- no hidden structural mistakes under flowing fabric

## Production order and QA gates

1. Create **Poster 1 — Draw a Full-Body Manhua Figure**
2. Owner checks:
   - full-body readability
   - construction clarity
   - anatomy
   - hair line clarity
   - whether a child can actually copy it
3. Revise until approved
4. Create **Poster 2 — Build Manhua Clothing from Simple Shapes**
5. Owner checks:
   - body remains understandable
   - clothing masses are simple
   - fold logic is clear
6. After Posters 1–2 are approved, decide whether Poster 3 adds real value
7. Save all approved originals to Library
8. Do not publish yet; hold for the combined refresh release
