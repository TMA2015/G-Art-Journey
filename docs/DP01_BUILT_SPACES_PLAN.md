## Purpose

Extend Draw Places beyond outdoor depth and one-point streets without turning the beginner path into a formal perspective course.

## Lesson 1 — Draw Boxes & Corners in Two-Point Perspective

**Working slug:** `two-point-boxes-corners`

Learning goal:
- understand what changes when an object corner faces the viewer
- keep verticals vertical
- send the two side families toward separate vanishing directions
- build simple boxes before drawing buildings or furniture

Suggested poster sequence:
1. Find the horizon / eye level.
2. Place one near vertical corner.
3. Send left edges toward the left vanishing point.
4. Send right edges toward the right vanishing point.
5. Close the box with verticals.
6. Compare a low, eye-level and high box.

Try it:
- draw three boxes at different heights using the same horizon

Remember:
- two-point perspective uses two horizontal directions; the vertical edges stay vertical in this beginner setup

Visual rule:
- use a simple room/building-block example, not a dense city scene
- clear construction lines
- generous whitespace
- avoid excessive colored boxes / UI-like panels

## Lesson 2 — Draw a Simple Room from Boxes

**Working slug:** `simple-room-from-boxes`

Prerequisite:
- Lesson 1 recommended, not locked

Learning goal:
- turn a two-point box system into a simple interior
- place floor/wall corners, furniture boxes and openings consistently

Suggested poster sequence:
1. Establish eye level and room corner.
2. Build floor/wall directions.
3. Add one large furniture box.
4. Add a second object at a different height.
5. Turn boxes into simple furniture / windows.
6. Clean the room and keep only useful construction.

Try it:
- draw the same room corner with one chair/table arrangement changed

Remember:
- solve the big box directions first; details should sit on top of the perspective, not replace it
