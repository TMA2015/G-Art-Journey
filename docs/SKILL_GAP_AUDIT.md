# G-Art Journey — Skill-Gap Audit

**Status:** PROPOSAL FOR OWNER REVIEW  
**Date:** 2026-10-03  
**Scope:** current live Learning Paths, active guides, Reference Library and the Phase 2 academic reference map  
**Purpose:** identify only the missing skills that materially improve the current self-learning routes.

## 1. Audit rule

A skill is a real gap only when at least one of these is true:
- a current Learning Path depends on it but only teaches it indirectly
- the skill appears repeatedly across topics without one clear transferable foundation lesson
- the academic reference map identifies it as foundational and current lessons do not teach it clearly enough
- learners would otherwise need to infer a difficult construction from style-specific examples

Do **not** create a new lesson merely because the topic is common in art courses.

## 3. Highest-priority gap — Gesture & Motion Basics

### Why this is a real gap

Current lessons use gesture, but learners do not yet receive one clear transferable explanation of:
- line of action
- direction / energy
- chest and hip relationship
- support / balance
- compression vs extension
- turning a stiff pose into a readable moving pose

The current material is fragmented:
- Standing Figure begins with a movement line
- Sitting Poses uses body tilt/support
- Manhua Movement teaches flow inside one style-specific character
- Cartoon Action teaches exaggeration
- Motion Reference Library supplies examples but does not teach construction

A beginner can therefore copy movement examples without fully understanding the common principle.

### Proposed lesson

**Working title:** Draw Gesture & Motion from Simple Lines  
**Working slug:** `gesture-motion-basics`  
**Category:** Human Drawing / Core Drawing Skill  
**Role:** transferable foundation, not a style lesson

Suggested teaching sequence:
1. Find one line of action.
2. Add chest and hips as two simple masses.
3. Show which side compresses and which side stretches.
4. Place the supporting leg / contact point.
5. Build a simple moving figure over the gesture.
6. Compare stiff vs flowing versions of the same pose.

**Learning Paths impact:** insert after **Figure Proportions** and before **Standing Figure** in Draw People. Add as a support option in Create Characters.

## 4. Second gap — Feet from Simple Forms

### Why it matters

Hands have a dedicated construction lesson, but feet currently appear only as small parts of standing, sitting, chibi and character poses.

For full-body drawing, feet do two jobs:
- anatomy / construction
- contact and balance

A learner can understand the whole figure but still lose the pose when the feet do not sit convincingly on the ground.

### Proposed lesson

**Working title:** Draw Feet from Simple Forms  
**Working slug:** `feet-simple-forms`

Suggested teaching sequence:
1. Block the ankle, heel and forefoot.
2. Compare top / side / three-quarter views.
3. Place the big toe side and toe group.
4. Show weight on a standing foot.
5. Simplify shoes without losing the foot direction.

**Learning Paths impact:** keep as **Explore more / support**, not mandatory core. Add beside Hands in Draw People and Create Characters.

## 5. Third gap — Simple Color Harmony

### Why this is a real gap

Current Digital Art explains **how to organize color layers**, and Watercolor explains **how paint behaves**, but neither path clearly teaches:
- hue vs value vs saturation
- warm / cool relationships
- choosing a small limited palette
- using one dominant color family plus a smaller accent
- checking whether color still reads when values are similar

The old Phase 2 roadmap listed **Soft Color Harmony**, and this is the main planned concept that still has no direct modern equivalent.

### Proposed lesson

**Working title:** Build a Simple Color Palette  
**Working slug:** `simple-color-harmony`

Suggested teaching sequence:
1. Separate hue, value and saturation.
2. Pick one dominant color family.
3. Add one neighboring/supporting color.
4. Add one small contrasting accent.
5. Test the same palette on a simple character or small scene.
6. Compare calm vs lively variants without changing the drawing.

**Medium choice:** software-neutral; examples can use flat painted swatches and a simple character/scene. It should not depend on a specific app.

**Learning Paths impact:**
- Digital Art: **Explore more** after the two current series
- Watercolor: optional color-planning helper
- Create Characters: optional support when the learner wants to color a design

## 6. Important, but not next

### Two-point perspective / rooms

The current Draw Places route teaches landscape depth and one-point street perspective well. Two-point perspective is useful for corners, boxes, furniture and rooms, but the current route does not require it to function.

**Decision:** later expansion. Add only when Draw Places grows beyond outdoor / one-point scenes.

Possible future lesson:
- **Draw Boxes & Rooms in Two-Point Perspective**

### General illustration composition

Composition is already taught well inside **Compose a Complete Landscape**. A universal character/illustration composition lesson would be useful only when G-Art Journey adds a path such as **Make an Illustration** or **Tell a Story with One Picture**.

**Decision:** defer.

### Observation tools: negative space / sighting

These are academically foundational, but a standalone technical lesson would currently feel more formal than the rest of G-Art Journey.

**Decision:** integrate gradually into Everyday Objects, portrait and future observation exercises rather than creating a dedicated poster now.

### Watercolor color mixing

Watercolor uses warm/cool colors and limited palettes already, but physical pigment mixing is not yet a dedicated lesson.

**Decision:** first build the general **Simple Color Harmony** concept. Later decide whether watercolor needs a medium-specific mixing lesson.

## 7. Explicit non-gaps

Do not create new lessons for these topics now:

- **Light & Value** — already covered strongly by Shade Simple Forms + Graphite Values + portrait/digital reinforcement.
- **Graphite edges / mark making** — covered by Pencil Control + Texture with Graphite.
- **Pencil portrait construction** — current Portrait + Facial Features already cover it.
- **Landscape depth** — covered by Depth Layers and Street perspective.
- **Water / reflections** — covered in pencil landscape and watercolor scene work.
- **Layers for Beginners** — superseded by the live Digital Art two-series structure.
- **Simple Skin Color** — superseded by Color a Face with Simple Layers.
- **Hair / Fabric / Hands** — already have dedicated transferable foundation lessons.

This prevents the old roadmap from causing duplicate content.

## 10. Roadmap conclusion

The current site is not missing a broad foundation curriculum. It already covers most high-value beginner skills.

The next expansion should be **small and surgical**:
- one movement foundation
- one missing anatomy support skill
- one cross-medium color foundation

After SG-01, pause again and reassess the Learning Paths before adding two-point perspective, room drawing, illustration composition or more Reference Library style sheets.
