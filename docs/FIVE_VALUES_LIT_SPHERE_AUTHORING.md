# Five Values & a Lit Sphere — production specification

Status: **active authoring; artwork not yet approved**

This is the first Phase 2B Core Drawing Skills poster.

## 1. Learning outcome

A beginner should understand that **value** means how light or dark something appears, and should be able to use a small five-step value scale to organize light and shadow on one simple sphere.

The poster should teach:
1. a five-value graphite scale
2. one clear light direction
3. light family versus shadow family
4. core shadow and reflected light
5. cast shadow and contact dark
6. how the same value plan turns a flat circle into a believable sphere

This is a form-and-light lesson, not a rendering-effects lesson.

## 2. Distinctness from the existing Visual Note

The site already has the short Visual Note `graphite-values` (“Light & Value”).

The new Core Drawing guide must go deeper rather than repeat it:
- the old note is a quick reminder / entry point
- the new guide is the complete beginner lesson with a real five-step scale, labeled sphere anatomy, shadow-family logic, reflected light and a practice sequence
- once the new guide is released, retire the old note to the new guide using the existing replacement mechanism

Do not publish two near-duplicate lessons as independent destinations.

## 4. Poster architecture

### A. Hero study — one lit sphere

Create this first as an independent QA unit.

Show:
- light-source arrow
- highlight
- light
- halftone
- core shadow
- reflected light
- cast shadow
- contact dark / occlusion area where sphere meets the ground

Keep the setup simple: one neutral sphere on one neutral surface.

Main idea:
**Light describes the form**

Important distinction:
- reflected light belongs to the shadow family; it should remain darker than the directly lit side
- highlight is not automatically pure white unless the material/light warrants it

### B. Five-value scale

Use five clearly separated swatches:
1. lightest
2. light
3. middle
4. dark
5. darkest

Teach:
- make the steps visibly different
- use the scale as a planning tool, not a law that every drawing must contain exactly five flat bands

### C. From flat circle to sphere

Use a short three-stage comparison:
1. circle
2. split light/shadow families
3. add core shadow, reflected light and cast shadow

The sphere identity/light direction must stay unchanged.

### D. Four key reminders

1. **Pick the light direction first.**
2. **Group light and shadow before blending.**
3. **Keep reflected light inside the shadow family.**
4. **Use the cast shadow to anchor the form.**

### E. Practice strip

Three small exercises:
- make your own five-value scale
- shade one sphere with a single light
- squint / zoom out and check whether the big light-shadow pattern still reads

## 5. Mandatory QA

- light direction is consistent
- highlight, light, halftone, core shadow, reflected light and cast shadow do not contradict each other
- reflected light stays darker than directly lit planes
- cast shadow falls away from the light source
- contact dark is strongest near the touching point, not randomly placed
- no smooth gradient hides the five-value teaching structure
- labels point to the intended regions
- value swatches remain distinct at mobile size
- sphere remains spherical rather than becoming a flat gradient circle
- canonical logo is present in the final public WebP
- final public output is checked after build; source-only QA is insufficient
